# Vipshyana's 3D Portfolio Website

A visually stunning 3D portfolio website for Vipshyana, a B.Tech 3rd-year Computer Science and Engineering student at Ashoka Institute of Technology & Management, Varanasi. This portfolio showcases her animation and digital illustration skills through immersive 3D environments, cinematic landing animations, interactive galleries, and animated UI elements.

## Features

- **Immersive 3D Experience**: Built with Three.js and React Three Fiber for stunning 3D visuals
- **Smooth Animations**: GSAP and Framer Motion for fluid animations and transitions
- **Fully Responsive**: Works across all devices and screen sizes
- **Interactive Gallery**: Categorized artwork display with modal viewing
- **Gamified Navigation**: Points-based navigation system for enhanced engagement
- **Project Timeline**: Visual storytelling of her creative journey
- **Sketch of the Day**: Rotating display of daily sketches
- **Contact Form**: With validation and submission feedback
- **Professional Resume**: Downloadable resume section

## Technologies Used

- **Frontend**: React.js, Vite
- **3D Graphics**: Three.js, React Three Fiber, React Three Drei
- **Animations**: GSAP, Framer Motion
- **Styling**: CSS3 with modern techniques
- **Routing**: React Router DOM

## Components

1. **Header** - Navigation and branding
2. **Hero3D** - Cinematic landing section with 3D elements
3. **About** - Professional bio and skills showcase
4. **Gallery** - Interactive artwork gallery with categories
5. **SketchOfTheDay** - Rotating daily sketch display
6. **ProjectTimeline** - Visual timeline of projects and achievements
7. **Resume** - Professional resume with download option
8. **Contact** - Contact form with validation
9. **Footer** - Additional navigation and copyright
10. **Background3D** - Particle background system
11. **LoadingScreen** - Animated loading experience
12. **GamifiedNav** - Points-based side navigation
13. **ScrollProgress** - Scroll position indicator

## Setup and Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Customization

To customize the portfolio for another user:

1. Update the content in each component file
2. Replace placeholder images with actual artwork
3. Modify color schemes in the CSS variables
4. Update contact information and social links

## Deployment

Build the project for production:
```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```
